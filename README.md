# CS-330-Computational-Graphics-and-Visualization


The new design skills that my project helped me develop were working with Visual Studio and utilizing OpenGL to recreate an image as a 3D scene. I learned how to analyze an image and identify the basic shapes that could be used to represent different objects. I also learned how important the placement, scale, and rotation of these shapes are when trying to recreate a specific image. Another skill I developed was incorporating textures and lighting to make the objects look more realistic and closer to the original image.

I worked slowly, making sure every change that I made would not break the code in a major way. I also made sure to keep a successful copy of my code in case anything happened to the current version. I started by identifying the shapes needed to recreate the image and worked on their placement and size before moving on to other elements. Once I was satisfied with the objects, I incorporated the textures and lighting. I followed this process because I wanted to make sure each part was working correctly before moving on to the next one.

I will continue to keep backup copies of my work in future projects. This is something that helped me throughout this project because there were instances where a change did not produce the results I expected. Having a previous working version made it easier to recover without having to start over. I will also continue to divide larger projects into smaller tasks and test each part before moving on to the next. This approach can help me identify errors earlier and make the development process more manageable.

A new development strategy that I used while working on my 3D scene was testing changes individually before making additional modifications. Since I was unfamiliar with OpenGL and graphics programming, I wanted to understand how each change affected the scene. For example, when working with lighting, I adjusted the position and properties of the light sources and ran the program to observe the results. This helped me determine which changes improved the appearance of the objects and which ones needed to be corrected. I also learned to use the existing functions in the program to create multiple objects without having to rewrite the same code each time.

Iteration played an important role in the development of my project. A lot of the code used to create the different figures followed the same format, with only a few changes to the scale, rotation, position, or texture. I was able to reuse this structure and make adjustments depending on the object I wanted to create. There were also instances where I had to modify an object multiple times before achieving the result I wanted. For example, I initially experimented with a torus for the circular hedge around the central tree, but eventually changed it to a cylinder because it better represented the original image. Each iteration allowed me to improve the appearance of the scene.

My approach to developing code evolved throughout the milestones by becoming more organized and comfortable with the tools I was using. During the earlier milestones, I was mainly focused on understanding how to create and position basic shapes in the scene. As the course progressed, I became more familiar with the functions and how different elements interacted with each other. I was then able to incorporate textures, lighting, and camera navigation into the project. By the final milestone, I had a better understanding of how to troubleshoot issues and make changes without affecting other parts of the program. I also became more confident in testing my work and identifying what needed to be improved.

Computational graphics and visualizations have provided me with new knowledge that I can apply throughout my Computer Science degree. Before this class, I had very little experience working with graphics programming, so learning how to use OpenGL and Visual Studio allowed me to expand my programming skills. I also gained more experience working with C++, organizing code, troubleshooting errors, and understanding how different functions work together. These skills can be useful in future courses because they have helped me become more comfortable working with unfamiliar programming tools and solving problems through testing and experimentation.
